The leader runs `calculateSuggestion` and decides where every follower goes. `ordered` has one entry per follower (the leader is not in it), sorted by id: `(id, (x, y))`, where `(x, y)` is the vector from that follower to the leader, so coordinates are relative to each follower, not absolute. The result maps each follower id to the vector, again relative to that follower, it should move along; the follower stops once this vector is shorter than `stabilityThreshold`. The leader does not move.
